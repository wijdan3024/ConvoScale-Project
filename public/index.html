📊 PostgreSQL Database Entity-Relationship (ER) Architecture

+-------------------------------------------------------------------------------------------------------------+
|                                      CONVOSCALE RELATIONAL SCHEMA                                           |
+-------------------------------------------------------------------------------------------------------------+

  [ USERS ] (1) <-----------------+ (N) [ SESSIONS ]
    id: UUID [PK]                 |       id: UUID [PK]
    email: VARCHAR(255) [UQ, IDX] |       user_id: UUID [FK -> users.id]
    password_hash: VARCHAR(255)   |       token_hash: VARCHAR(255) [UQ, IDX]
    name: VARCHAR(255)            |       expires_at: TIMESTAMP [IDX]
    created_at: TIMESTAMP         |
                                  |
                                  + (N) [ CONVERSATIONS ] (1) <------------+ (N) [ MESSAGES ]
                                          id: UUID [PK]                    |       id: UUID [PK]
                                          user_id: UUID [FK -> users.id]   |       conversation_id: UUID [FK]
                                          title: VARCHAR(255)              |       sender_type: USER | CHATBOT
                                          message_count: INT               |       content: TEXT
                                          last_message_at: TIMESTAMP       |       sequence_number: INT [IDX]
                                          updated_at: TIMESTAMP [IDX]      |       request_id: VARCHAR [UQ, IDX]
                                                                           |       created_at: TIMESTAMP [IDX]
  [ CHATBOT_RESPONSES ]                                                    |
    id: UUID [PK]                                                          + (N) [ IDEMPOTENCY_KEYS ]
    trigger_type: COMMAND | KEYWORD | EXACT | DEFAULT                              id: UUID [PK]
    pattern_or_keyword: VARCHAR [IDX]                                              key: VARCHAR [UQ with user_id]
    response_template: TEXT                                                        endpoint: VARCHAR
    priority: INT [IDX]                                                            status: PROCESSING | COMPLETED
    is_active: BOOLEAN [IDX]                                                       response_body: JSONB / TEXT

📖 REST API Endpoints Specification

POST /api/auth/login - Authenticate user and receive JWT Bearer token
Payload: {"email": "demo@convoscale.io", "password": "password123"}
GET /api/conversations - List user conversations with cursor pagination (limit, cursor)
POST /api/conversations/:id/messages - Atomic message transaction & bot response with X-Idempotency-Key
Headers: { "Authorization": "Bearer <token>", "X-Idempotency-Key": "req_123" }
GET /health - Health check reporting database status, connection pool, cache, and memory
GET /api/metrics - Live telemetry snapshots: RPM, RPS, P50/P95/P99 latencies, error counts
